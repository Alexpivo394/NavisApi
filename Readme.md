## Libraries for Navisworks add-ins development

This repository contains libraries for creating Navisworks add-ins. All files are packed into separate Nuget packages for easy connection to your project. Only original files from the
latest [Navisworks](https://www.autodesk.com/products/navisworks) installation image are used.

The package version matches the Navisworks release, e.g. use `2024.*` for Navisworks 2024.

Didn't find the library you need? [Tell me](https://github.com/Alexpivo394/NavisApi/issues/new)
